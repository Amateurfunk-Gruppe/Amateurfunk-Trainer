Cache leeren?

Geschützt und bleibt erhalten:
• Verlauf (alle 3 Benutzer)
• Lernbedarf (schwierige Fragen)
• Lernfortschritt (beherrschte Fragen)
• Fehlerlisten
Gelöscht wird:
• Service Worker Cache
• TTS Cache
• Temporäre Einstellungen
Die Seite wird danach neu geladen. Verlauf etc. wird aus Datei wiederhergestellt.

Alles zurücksetzen?

Wird unwiderruflich gelöscht (für diesen Benutzer):
• Fehlerliste (alle gemerkten falschen Antworten)
• Lernbedarf (als "schwierig" markierte Fragen)
• Lernfortschritt (als "beherrscht" markierte Fragen)
Bleibt erhalten:
• Prüfungsverlauf (bisherige Prüfungsergebnisse)
• Die anderen beiden Benutzer
Das kann nicht rückgängig gemacht werden. Die Seite wird danach neu geladen.

Lernfortschritt zurücksetzen?

Was passiert:
• 0 als gelernt markierte Fragen werden zurückgesetzt
• Fragen erscheinen wieder im normalen Lernmodus
• Verlauf, Fehlerliste und schwierige Fragen bleiben erhalten
Hinweis:
Das kann nicht rückgängig gemacht werden.
