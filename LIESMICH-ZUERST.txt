Amateurfunk-Trainer - das hier ist der QUELLTEXT
================================================

Wenn du diese Datei liest, hast du vermutlich auf GitHub "Source code
(zip)" oder "Code - Download ZIP" geladen. Das ist der Quelltext des
Trainers - zum Lesen, Pruefen und Mitentwickeln. Es fehlen darin drei
Dinge, die nicht in ein Quelltext-Archiv gehoeren:

  - node\          Node.js, das den Server ausfuehrt (rund 90 MB)
  - node_modules\  die drei Module des Servers (express, socket.io, cors)
  - piper\         die Sprachausgabe mit den Stimmen (mehrere hundert MB)

Ohne node_modules\ startet der Server nicht. START.bat sagt das seit
1.298.0 in einem Fenster; davor kam nur die Frage nach Node.js, und
danach tat sich nichts mehr.

DAS FERTIGE PROGRAMM

  Liegt auf der Release-Seite ganz oben und heisst

      Amateurfunk-Trainer-<Version>-windows.zip     (rund 340 MB)

  github.com/Amateurfunk-Gruppe/Amateurfunk-Trainer/releases

  Darin ist alles: Node, die Module, die Stimmen, der ganze Katalog.
  Auspacken (nicht nach C:\Program Files), START.bat doppelklicken,
  fertig. Nichts wird in Windows installiert.

WER DEN QUELLTEXT ABSICHTLICH HAT

  Windows:  Node.js 18 oder neuer installieren (nodejs.org - npm ist
            dabei). Dann im Ordner einmal

                npm install

            ausfuehren, danach START.bat. Beim ersten Mal fragt es,
            ob es sich ein eigenes Node in den Ordner node\ holen
            darf - START.bat benutzt nur dieses, nie das installierte.
            Die Sprachausgabe holt der Trainer bei Bedarf:
            Einstellungen -> Wartung -> Hilfsprogramme -> Piper "Holen".

  Linux und Mac:  installieren.sh macht alles in einem Rutsch, siehe
            INSTALLATION.md. Von Hand: npm install, dann ./START.sh.

DEIN LERNSTAND

  Er liegt in data\ hier im Ordner. Wer den Ordner kopiert, nimmt ihn
  mit. Wer den Ordner loescht, loescht ihn - vorher im Trainer ueber
  "Sichern" eine Kopie anlegen.

BEENDEN

  STOP.bat doppelklicken, oder im Trainer oben rechts auf "Beenden".
  Danach ist der Trainer wirklich aus - ein Browserfenster allein
  bringt ihn nicht zurueck.
